# 병합 내역 (2026-10-24)
기준: 최종파일(원본) + SCARGO_Final_Merged_Verified(팀 합본)

## 방식
- 합본의 변경분을 최종파일에 반영, 덮어쓴 원본은 `_병합전_백업` 에 보관
- 직접 고친 부분 이식: AMR 충전 로직(AmrBackgroundSim), SbotDashboard 상태 필터, amrTwinApp 초기 시드, 날씨 API 키 기본값, DB 비밀번호 기본값(1234)
- AmrAuthConfig(인터셉터 인증)는 AmrTokenAuthenticationFilter + AmrAccessPolicy 로 대체되어 빈 파일로 남김

## 실행 전 필수
1. DB: `DB/SCARGO_Integrated_Full_Install_20261024.sql` 을 **새 DB**(기본 scargo_demo)에 1회 설치 (재실행 불가)
2. 비밀번호: 기본 1234, 다르면 환경변수 SCARGO_DB_PASSWORD 또는 application-local.yml
3. Gradle Wrapper 8.10.2 (첫 실행 시 다운로드)
4. 프론트: npm install 후 npm run dev
