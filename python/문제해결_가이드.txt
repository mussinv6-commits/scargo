====================================================
 PlateDetect 문제 해결 가이드
====================================================
exe 실행 중 문제가 생기면 아래에서 비슷한 증상을 먼저 찾아보세요.


[1] "학습된 모델(best.pt)을 찾지 못했습니다" 오류가 뜸
----------------------------------------------------
원인: 이 프로그램은 exe와 같은 폴더에 있는 runs\detect 폴더에서 학습된 모델을
     찾습니다. runs\detect 폴더가 없으면 이 오류가 납니다.
해결: PlateDetect.exe가 있는 폴더 안에 runs\detect 폴더(학습 결과)를 통째로
     복사해 넣어주세요.
     예) PlateDetect.exe
         runs\detect\plate_detect_m\weights\best.pt
         runs\detect\plate_detect_m\results.csv   <- 성능 정보 표시에도 필요
     이렇게 넣어두면 다른 PC로 폴더째 복사해서 옮겨도 그대로 동작합니다.


[2] 첫 실행이 느리거나, 백신 프로그램이 경고를 띄움
----------------------------------------------------
원인: PyInstaller로 만든 exe는 서명이 없어서 Windows Defender나 백신이
     낯선 프로그램으로 인식해 검사하거나 오탐 경고를 띄우는 경우가 흔합니다.
해결: "추가 정보 > 실행" 또는 백신 프로그램에서 예외 처리해주세요.
     첫 실행 시 OCR 엔진을 불러오는 데도 최대 1분 정도 걸릴 수 있습니다
     (화면 하단 SYSTEM LOG에 "OCR 엔진 로딩 중..." 이라고 뜨면 정상 - 기다리면 됨).


[3] 번호판이 있는데 박스가 아예 안 잡힘
----------------------------------------------------
원인: 화면 오른쪽 MODEL 아래 conf 값이 검출 기준입니다. 기본값이 0.9로
     엄격하게 설정돼 있어서, 각도가 안 좋거나 흐릿한 번호판은 기준을
     못 넘어 아예 안 잡힐 수 있습니다.
해결: 이 경우 conf 기준에는 못 미치지만 참고할 만한 후보가 있으면
     빨간 점선 박스로 자동 표시됩니다 (박스 라벨에 "⚠ 실제 확신도(%)"가
     같이 뜸). 이 박스를 모서리 드래그로 번호판에 맞게 조정한 뒤
     "선택한 박스만 다시 인식"을 누르면 됩니다.
     그래도 아무 박스도 안 뜨면, 빈 곳을 드래그해서 직접 박스를 그리면 됩니다.


[4] 글자를 이상하게 읽음 (번호판과 다른 글자가 나옴)
----------------------------------------------------
원인: 대부분 박스가 번호판을 딱 맞게 감싸지 못해서 생깁니다. 특히 직접
     그렸거나 [3]의 참고용(빨간 점선) 박스는 YOLO가 딱 맞춰준 박스보다
     부정확할 수 있습니다.
해결: 박스를 클릭해서 선택한 뒤, 모서리를 드래그해 번호판 테두리에
     최대한 딱 맞게 조정하고 "선택한 박스만 다시 인식"을 눌러주세요.
     그래도 안 되면 "(판독 불가)"로 두는 게 잘못된 번호로 저장하는 것보다
     안전합니다.


[5] 인터넷이 안 되는 PC에서 처음 실행 시 멈추거나 오류
----------------------------------------------------
원인: OCR 엔진(EasyOCR)이 처음 실행될 때 한글/영문 인식 모델 파일을
     인터넷에서 자동으로 내려받습니다. 인터넷이 안 되면 이 단계에서
     실패합니다.
해결: 인터넷이 되는 PC에서 한 번 실행해 정상적으로 OCR까지 마친 뒤,
     사용자 폴더의 .EasyOCR 캐시 폴더(보통 C:\Users\사용자명\.EasyOCR)를
     PlateDetect.exe와 같은 폴더에 복사해두면, 인터넷이 없는 PC에서도
     바로 동작합니다.


[6] 창이 화면보다 크게 뜨거나 버튼이 화면 밖으로 잘려 보임
----------------------------------------------------
원인: Windows 디스플레이 배율(125%, 150% 등) 설정과 충돌하는 경우입니다.
해결: 최근 버전에서 이 문제를 해결했습니다. 그래도 창을 작게 줄이면
     오른쪽 MODEL~RESULT 영역이 스크롤로 전부 보이도록 되어 있으니,
     스크롤을 내려서 확인해주세요.


[7] 그 밖의 오류 - 프로그램이 조용히 꺼지거나 이상하게 동작함
----------------------------------------------------
확인: PlateDetect.exe와 같은 폴더에 생기는 crash_log.txt 파일을 열어보면
     마지막에 무슨 오류였는지 기록이 남아있습니다. 문제를 문의할 때
     이 파일 내용을 같이 보내주시면 원인 파악이 훨씬 빠릅니다.
