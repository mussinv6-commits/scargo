# 프론트 통합 내역

CSS 적용 버전을 기준으로 OCR 기능 추가 버전의 변경을 통합했습니다.

- 기존 CSS, 홈 슬라이드, 로고, 관리자 공지사항, 기사 정보와 메뉴, 날짜 조회 기능 유지.
- GateDemo: OCR 게이트인/게이트아웃, 구내 차량 목록, 상하차 완료 및 과적 통과 상태 조회 통합.
- AdminWeighbridge: 컨테이너/화물 중량 구성, VGM 전달, 적재중량 위반 표시, 이동 경로 미니 플레이어 통합.
- WeighbridgeRouteMap 및 truck_route.png 추가.
- OCR 버전에만 있던 bbs/bbsScroll 컴포넌트와 /bbslist, /bbswrite, /bbsdetail, /scrlist, /bbsupdate 라우트 추가.
- 출차 성공 시 실패 안내가 함께 표시되던 조건 수정.
- 축중 수동 변경 시 이전 시뮬레이션 중량 구성과 좌우 측정값을 초기화하여 오래된 값이 저장되지 않도록 수정.

## 실행

Node.js에서 압축을 풀고 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

배포용 빌드: npm run build

## 확인 범위

제공된 node_modules를 이용한 Vite 프로덕션 빌드 성공.
백엔드 및 OCR 서버가 첨부되지 않아 실제 로그인, OCR 인식, API 저장/조회와 지도 API 응답은 검증하지 못했습니다.
기존 API 주소 설정은 src/utils/apiBase.js와 src/utils/gateApiBase.js를 사용합니다.
OCR 기능에는 기존 서버의 scanType/vehicleNo 파라미터 지원과 계량 route/VGM API 지원이 필요합니다.
node_modules와 dist는 결과 압축에 포함하지 않았습니다.
기존 README.md와 MERGE_NOTES.md는 원본 프로젝트 설명으로 유지했습니다.
