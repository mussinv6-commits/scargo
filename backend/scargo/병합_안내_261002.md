# 백엔드 폴더 통합 (2026-10-02)

`SCargo_1001 _am11/scargo` (팀원 통합본) + `backend/scargo` (계중대 작업본) → **`backend/scargo` 하나로 통합**

## 기준
- 팀원 통합본(`scargo/`)을 기준으로 가져옴: OCR 입차/출차 워크플로우(TruckWorkflowService), 알림 개선, PENDING 상태, 기사 알림(DriverAlertService), 매핑 수정 등 33개 파일
- 계중대 작업본에만 있던 것 5가지를 그 위에 더함

| 파일 | 더한 내용 |
| --- | --- |
| `service/WeighbridgeRouteService.java` | 지도 경로 계산 (신규) |
| `dto/WeighbridgeRouteResponse.java` | 지도 경로 응답 (신규) |
| `controller/WeighbridgeController.java` | `GET /api/v1/weighbridge/route` 추가 |
| `SecurityConfig.java` | `/error` 공개, 미로그인 401 구분 (팀원의 필터 중복등록 방지 코드는 유지) |
| `application.yml` | `server.servlet.session.persistent: false` |

## 확인
- 두 폴더에서 같은 이름 파일은 전부 비교함. 위 5가지 외에는 팀원본이 더 최신(내용 포함 관계)
